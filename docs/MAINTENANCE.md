# 主页维护

这是 Alinerml 的 GitHub Profile README。

- 修改 `README.md` 即可更新简介、项目、技术标签和排版。
- 动态打字标题在 `assets/hello.svg`，直接编辑文本即可。
- `Update profile visuals` 工作流每天北京时间 09:23 左右更新贪吃蛇、统计卡片与立体贡献图，也可在 Actions 中手动运行。GitHub 定时执行可能延迟。
- 工作流只使用 GitHub 自动提供的临时 `GITHUB_TOKEN`，无需额外个人令牌。只展示公开可读取的数据，语言比例表示仓库代码分布，不代表熟练度。
- 图片先完整生成并通过校验再提交。生成失败时，主页保留上一次成功的图片。
- 参考主页的博客、WakaTime、收款码、赞助和社交账号没有复制；这些需要账号所有者自己的真实资料才能接入。
- 长期没有活动的公开仓库可能被 GitHub 暂停定时工作流；在 Actions 重新启用即可。

## 视觉来源

布局灵感来自 [sun0225SUN](https://github.com/sun0225SUN/sun0225SUN)。插画和装饰动画通过固定版本的原仓库链接引用，保留原来源，未复制作者的个人信息和统计。

- [Platane/snk](https://github.com/Platane/snk)：贡献贪吃蛇。
- [GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib)：立体贡献图。
- [GitHub Readme Stats Action](https://github.com/stats-organization/github-readme-stats-action)：将真实统计生成并保存到本仓库，不依赖公共统计图片服务器。
- [Shields.io](https://shields.io)：技术与导航徽章。

引用原仓库的装饰图和 Shields.io 徽章仍依赖外部服务；核心贡献与统计图片由本仓库托管。
